# Правила проекта: сайт-портфолио Софьи

- Стек: чистые HTML + CSS + JS. Без фреймворков, без админки, без сборщиков.
- Источник дизайна: Figma, файл 391K09vokCEzV65Sznaj7B. Значения берём только из макета, не «на глаз».
- Все цвета, шрифты, отступы и радиусы — через CSS-переменные из tokens.css.
- Картинки лежат в assets/img, список — в IMAGES.md. Имена файлов не менять.
- Не придумывать факты, цифры, отзывы и цитаты. Не хватает данных — спросить.
- Работать по одному блоку. После каждого блока показать результат и ждать «ок».
- Не трогать файлы и блоки, о которых не просили.
- Главный план работы — в промт.md.
